Usage
- SVGs have transparent backgrounds unless explicitly named "...background.svg".
- Use <img>, CSS background-image, or inline SVG.
- For subtle page decoration, opacity around 0.35–0.55 usually matches the mockups.
- Keep large leaves clipped at container edges for the same visual feel.
